# 🚀 ELDALY STREAM — Backend Server

خادم الباك اند المستقل لبرنامج **ELDALY STREAM**.
يوفر REST API و WebSocket للبث والتفاعل مع TikTok LIVE، بالإضافة للتحقق من التراخيص ومزامنة بيانات المستخدمين مع قاعدة البيانات السحابية (Firestore).

---

## 📋 المميزات

- **TikTok LIVE Connector**: اتصال مباشر وبث أحداث تيك توك لايف (الهدايا، التعليقات، اللايكات، المتابعين، الشير).
- **Firebase Auth & Firestore**: التحقق من التراخيص، الاشتراكات، ومزامنة Patreon التلقائية.
- **تخزين سحابي للحسابات**: البروفايلات والأكشنز والإيفنتات وإعدادات الويدجت بتتحفظ في Firestore مش على الجهاز — المستخدم يقدر يسجل دخول من أي جهاز يلاقي بياناته.
- **تمرير أحداث الأوفرلاي**: صفحات OBS (الأوفرلاي والويدجت) بتتقدم من تطبيق الديسكتوب على جهاز المستخدم نفسه، والباك إند بيبعتله الأحداث عبر WebSocket — كل مستخدم ليه توكن سداسي (hex) فريد بيحمي روابطه.
- **Edge TTS & Google TTS**: توليد الأصوات والتعليقات الصوتية بدقة عالية.

---

## 🏗️ البنية الجديدة للأوفرلاي

```
[TikTok LIVE] → [Backend (هنا)] → WebSocket (ov:*) → [تطبيق الديسكتوب]
                                                        ↓
                                        سيرفر محلي 127.0.0.1:7330
                                                        ↓
                                          OBS Browser Source
                              /overlay/<token>/<screen>
                              /widget/<token>/<name>?id=...
```

- كل حساب ليه **overlayToken** (32 حرف سداسي) بيتولد تلقائيًا أول تسجيل دخول وبيتحفظ في مستند المستخدم في Firestore.
- روابط OBS كلها محمية بالتوكن ده — محدش يقدر يوصل لأوفرلاي حد تاني حتى لو عرف البورت.
- الطوابير (queue) وإدارة "خلص الميديا" بقت في تطبيق الديسكتوب — الباك إند بيرّفع الأحداث بس.

## 🛠️ التشغيل السريع (Local Development)

```bash
cd backend
npm install
npm start
```

- **REST & WebSocket API**: `http://127.0.0.1:3000` (WebSocket على `ws://127.0.0.1:3000/ws`)
- السيرفر بيقف على `127.0.0.1` افتراضيًا — عشان تسمح بالوصول من بره غيّر `HOST=0.0.0.0` في `.env` (وممكن تستخدم reverse proxy بـ TLS).

## 🔐 حماية الـ API

- بعد تسجيل الدخول بيرجع `sessionToken` في الرد — كل نداءات `/api/*` (عدا المسارات العامة زي login/register/health/webhook) لازم تبعتله في هيدر `x-app-session` وإلا بترجع 401.
- Rate limiting على مسارات الدخول/التسجيل (25 محاولة/دقيقة لكل IP).
- هيدرز أمان أساسية على كل الردود.

## ☁️ التخزين السحابي للبروفايلات

- بيانات كل حساب بتتحفظ في `users/{email}/app/main` في Firestore كحقول JSON لكل مفتاح رئيسي.
- الحفظ مؤجل (debounced ~1.2 ثانية) وتلقائي قبل إقفال السيرفر.
- لو النت قطع، النظام بيشتغل على كاش محلي ويرجع يزامن أول ما النت يرجع.
- **مهم — قواعد أمان Firestore**: اتأكد إن القواعد بتسمح لكل مستخدم بقراءة/كتابة مستنده هو بس:

```
match /databases/{database}/documents {
  match /users/{email} {
    allow read, write: if request.auth != null && request.auth.token.email == email;
    match /{document=**} {
      allow read, write: if request.auth != null && request.auth.token.email == email;
    }
  }
}
```

- مفتاح الـ Web API بتاع Firebase عام بطبيعته (ده التصميم بتاعهم) — الأمان الحقيقي في القواعد فوق دي.

## 🌐 الرفع على الاستضافة

### 1. نسخة مشفّرة (موصى بها)

```bash
cd backend
npm run build        # بينتج مجلد deploy/ بكود V8 bytecode — بدون مصدر مقروء
# ارفع مجلد deploy على السيرفر ثم:
cd deploy
npm install --omit=dev
pm2 start boot.js --name "eldaly-backend"
```

> ⚠️ الـ bytecode مرتبط بنسخة V8 — اتأكد إن إصدار Node على السيرفر هو نفسه
> الإصدار الكبير (major) اللي اتجمع بيه محليًا.

### 2. تشغيل عادي بالمصدر (تطوير)

```bash
pm2 start src/server.js --name "eldaly-backend"
```

### متغيرات البيئة

- `PORT` — بورت الـ API (افتراضي 3000)
- `HOST` — عنوان الاستماع (افتراضي 127.0.0.1 — استخدم 0.0.0.0 بس لو محتاج وصول خارجي)
- `DATA_DIR` — مجلد الكاش المحلي (افتراضي ./data)
